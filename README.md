# DemoAgent Landing

Лендинг под AI-агента в стиле структуры Yadaphone с обязательной RU-версией и EN-версией.

## Что реализовано

- RU-страница: `index.html`
- EN-страница: `en/index.html`
- Общие стили: `styles.css`
- Интерактив: `script.js`

## Блоки страницы

1. Header с якорным меню, CTA и переключателем языка.
2. Hero с двумя CTA и демо-чатом (включая кнопку сброса).
3. «Как это работает в 3 шага».
4. «AI-агент для бизнеса».
5. Видео-блок с lazy loading.
6. Блок преимуществ.
7. Сравнительная таблица (адаптив с горизонтальным скроллом).
8. Тарифы + форма заявки.
9. Отзывы.
10. FAQ (accordion via `details/summary`).
11. Футер с контактами и юридическими ссылками.

## Use-cases для контента студии (7 шт.)

1. E-commerce: ответы по доставке, оплате и возвратам.
2. Сфера услуг: квалификация заявок и запись на консультации.
3. B2B: первичный пресейл и маршрутизация лидов в CRM.
4. Образование: ответы по программам, стоимости и расписанию.
5. Медицинские услуги: FAQ и запись на первичный прием.
6. Недвижимость: подбор объектов по параметрам и назначение показов.
7. SaaS: поддержка onboarding и FAQ по функциональности.

## Интеграции и аналитика

- В `script.js` добавлен пример отправки формы в webhook (`https://example.com/webhook`).
- Для аналитики используется `dataLayer.push` (события CTA/форм/чата).
- В production заменить endpoint webhook и добавить GTM/GA4 контейнер.

## Локальный запуск

```bash
python -m http.server 4173
```

Открыть:
- RU: `http://localhost:4173/`
- EN: `http://localhost:4173/en/`
